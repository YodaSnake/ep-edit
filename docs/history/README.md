# Historical Design Documents

Files in this directory are retained for design history and architectural rationale.

They are not current product authority.

`EP_Deterministic_Copy_Paste_Edit_CLI_Design_v0.1.txt` is the pre-extraction working design that preceded the standalone `ep-edit` repository. It preserves the original motivation, architectural principles, and early design decisions, but it also contains details that have since been superseded, including parts of the authoring grammar, edit identity model, and later lifecycle behavior.

For current behavior and implementation requirements, use the current repository source, tests, and maintained user-facing documentation as authority. Git history records subsequent evolution.

Do not implement or restore behavior solely from the historical design document without reconciling it against current source, tests, and current documentation.
